Animated gradient border

@property makes an angle animatable, so a conic gradient can spin.

No JS, no SVG
just a typed custom property
Show CSS
@property --angle {
  syntax: "<angle>"; initial-value: 0deg; inherits: false;
}
.card::before {
  content: ""; position: absolute; inset: -2px; z-index: -1;
  background: conic-gradient(from var(--angle), #7c5cff, #00e5c3, transparent 40%, #7c5cff);
  animation: spin 4s linear infinite;
}
@keyframes spin { to { --angle: 360deg; } }

Magnetic button

The button leans toward your cursor and springs back.

Show CSS
.mag button {
  transition: transform .25s cubic-bezier(.2, .9, .3, 1.4); /* overshoot = spring */
  will-change: transform;
}

Particle network

Canvas 2D. Dots drift, link when close, and flee your cursor.

Show JS
for (const p of dots) {
  p.x += p.vx; p.y += p.vy;                     // drift
  const dx = p.x - mouse.x, dy = p.y - mouse.y;
  if (dx*dx + dy*dy < 90*90) { p.x += dx * .02; p.y += dy * .02; } // repel
}
// connect pairs closer than 90px, alpha = 1 - dist/90
// pause with IntersectionObserver when off screen

View Transitions theme swap

Click the theme button in the nav: the new theme grows as a circle from where you clicked.

Show JS + CSS
button.onclick = (e) => {
  root.style.setProperty("--x", e.clientX + "px");
  root.style.setProperty("--y", e.clientY + "px");
  document.startViewTransition(() => toggleTheme());
};
::view-transition-new(root) {
  animation: reveal .7s both;
  clip-path: circle(0 at var(--x) var(--y));
}
@keyframes reveal { to { clip-path: circle(150% at var(--x) var(--y)); } }
